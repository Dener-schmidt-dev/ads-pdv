# Atalhos da tela de venda

| Tecla | Ação |
|-------|------|
| F2 | Cliente (busca rápida) |
| F3 | Alterar quantidade do item selecionado |
| F4 | Desconto |
| F5 | Finalizar venda |
| F6 | Cancelar venda |
| Delete | Remover item |
| Esc | Fechar modal / voltar |
| Enter | Confirmar no modal ativo |
| Setas ↑↓ | Navegar autocomplete de produtos |

## Comportamento do campo de busca

- Foco automático ao abrir a tela
- Foco recuperado após adicionar produto
- Código de barras: inclusão imediata
- Texto: autocomplete com debounce curto
- Mesmo código repetido: incrementa quantidade
